# Wallify

Wallify 是 Wallify 壁纸分享网站的移动应用。你可以在应用内发现、搜索、收藏、下载和上传壁纸，也可以管理自己的账户资料；常用操作不需要跳转浏览器。

当前版本：**v1.7.455**

## 你可以做什么

| 功能 | 使用方式 |
| --- | --- |
| 发现壁纸 | 浏览最新上传、游戏分类和随机二次元内容。 |
| 搜索内容 | 输入角色、标题或游戏名称，快速找到感兴趣的壁纸。 |
| 查看与保存 | 在详情页查看原图信息，并保存图片到系统相册或通过系统分享。 |
| 收藏壁纸 | 将喜欢的壁纸加入收藏，方便之后再次查看。 |
| 上传壁纸 | 登录后选择手机中的图片，在应用内完成发布。 |
| 管理资料 | 编辑昵称、邮箱、个人简介和头像。 |

## 上传图片

在 Android 设备上，点击“上传”后会打开手机系统提供的图片选择入口。小米设备通常会显示“安全访问”、相册或文件管理等可用来源；选择“安全访问”后即可从系统界面挑选图片。每次上传仅选择一张图片，应用会在上传过程中显示明确的等待提示。

## 网络或服务器异常

如果 Wallify 官网暂时不可用、网络中断或服务器返回错误，应用会显示清晰的说明和“重新连接”按钮。部分页面会继续保留已加载的内容，避免页面突然变为空白。官网服务恢复后，点击“重新连接”即可再次加载。

> 如果官网正在维护，应用无法替代服务器恢复内容；请稍后重新连接。

## 获取更新与反馈

新版本发布后，请下载并安装最新 APK。应用设置页中的“检查更新”可查看当前安装版本。使用过程中如遇到问题或有功能建议，请通过 [GitHub Issues](https://github.com/Nebula-Lanye/wallifyApp/issues)或通过邮箱（lkr2312@163.com） 提交反馈，并尽量说明手机型号、系统版本和复现步骤。
