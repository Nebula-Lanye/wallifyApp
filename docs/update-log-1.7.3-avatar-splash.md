# Wallify v1.7.3 更新日志

## 资料编辑支持更换头像

“编辑个人资料”页面现已加入原生头像编辑入口。已登录用户可以从系统相册选择一张方形头像，应用会在保存前显示本地预览；保存时，头像会连同用户名、邮箱和个人简介一起同步到 Wallify 账户与公开主页。

头像上传通过应用内现有的登录会话、CSRF 校验和受限服务端代理完成，不需要跳转浏览器。系统支持 JPG、PNG、WebP 和 GIF 格式，单张头像大小限制为 5MB。保存成功后，应用会刷新本地账户资料，并以缓存破坏参数重新加载公开头像。

## 修复第一段原生启动页 Logo 裁切

此前 Android 原生启动屏使用横向比例过宽的 Logo 资源，系统在启动画面的安全区域内缩放时会放大并裁掉右侧字母，导致第一屏显示不完整。现在第一段启动屏改用带安全留白的方形 Android 前景资源，并将显示宽度调整为 176，使完整标识能够在 Android 的居中安全区域内展示。

## 缩小第二段应用内启动 Logo

第二段启动画面保留 Wallify 官方横版 Logo 和深灰背景，但不再把整张纵向合成图铺满屏幕。Logo 现以独立图片在页面下三分之一位置展示，宽度调整为屏幕的 54%，因此文字更小、更清晰，也不会占据过多视觉空间。

## 验证结果

本次更新已通过 TypeScript 类型检查、12 项自动化测试（1 项按现有配置跳过）、Expo 配置解析以及移动尺寸主页和资料编辑页预览。头像上传涉及用户已登录的 Wallify 站点会话，最终的相册选择、真实上传和头像刷新需要在新 Android APK 中用已登录账号完成一次实机验证。

| 项目 | 更新前 | 更新后 |
| --- | --- | --- |
| 编辑个人资料 | 只能修改用户名、邮箱和个人简介 | 支持从相册选择、预览并上传头像 |
| 原生启动页第一屏 | 横版 Logo 被系统放大并裁切 | 使用带留白的方形安全资源，完整显示标识 |
| 应用内启动页第二屏 | Logo 文字偏大 | 保留下三分之一布局，缩小到 54% 屏幕宽度 |

> 建议在 GitHub Actions 重新生成 Android APK 后，依次验证冷启动、热启动、头像相册选择、头像保存和设置页头像刷新。
