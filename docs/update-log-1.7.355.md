# Wallify v1.7.355 更新日志

## 版本概览

v1.7.355 合并了 v1.7.3 与 v1.7.305 的头像编辑、上传反馈和启动页修复，并解决 Android 壁纸上传没有进入小米“安全访问”等系统文件提供器的问题。为了支持覆盖安装，本次将 Android `versionCode` 和 iOS `buildNumber` 均递增至 **5**。

## Android 系统图片选择器

壁纸上传在 Android 设备上现调用系统文件提供器的图片选择请求，而不再展示应用自建的相册网格。请求被限制为 `image/*`、单文件选择，并将文件复制到应用缓存目录以保障后续上传读取稳定。

在小米设备上，系统会根据已安装的提供器显示“安全访问”、相册、文件管理或其他系统来源；选择“安全访问”即可在该系统组件内选取图片。Wallify 不再枚举或展示设备中完整相册内容，也不会请求完整图库读取权限。由于来源列表由 Android 和 MIUI 系统管理，应用无法强制只显示单一厂商入口，但会始终限制为图片文件。

## 原生头像编辑与同步

“编辑个人资料”页面支持从系统相册选择方形头像，在保存前显示本地预览，并将头像、用户名、邮箱和个人简介同步到 Wallify 账户及公开主页。头像支持 JPG、PNG、WebP 和 GIF，单张文件上限为 5MB。保存成功后会刷新资料缓存，避免设置页继续显示旧头像。

## 头像上传过程反馈

头像上传期间，头像预览会显示半透明遮罩和活动指示器，文案切换为“正在上传头像…”。保存按钮会同步显示“正在上传头像…”或“正在保存资料…”，并临时禁用再次选图和重复提交。上传成功或失败后会显示明确提示。

## 两段启动页视觉修复

第一段 Android 原生启动屏改用带安全留白的方形 Logo 前景资源，显示宽度调整为 176，避免系统缩放时裁切横版字标。第二段应用内启动画面保留深灰背景和官方横版 Logo，但改为在下三分之一位置以屏幕宽度 54% 的独立图片展示，减小文字体积并增强可读性。

## 验证结果

本次版本通过了 TypeScript 类型检查、系统选择器配置专项测试、全量自动化测试和 Expo 配置解析。当前自动化测试结果为 **13 项通过、1 项按现有配置跳过**。由于小米“安全访问”的可用来源由实机系统决定，仍建议在新 APK 中完成一次真实选图与上传验证。

| 项目 | v1.7.355 表现 |
| --- | --- |
| Android 上传选图 | 调用系统文件提供器，限制单张 `image/*` 图片 |
| 小米安全访问 | 作为 MIUI 系统可用来源之一，由系统选择器展示 |
| 头像编辑 | 支持相册选择、预览、上传、缓存刷新与加载反馈 |
| 启动页第一阶段 | 使用安全方形 Logo，避免裁切 |
| 启动页第二阶段 | Logo 缩小至 54% 屏幕宽度，下三分之一展示 |
| 覆盖安装 | Android `versionCode: 5`，iOS `buildNumber: 5` |

> 建议重新运行 GitHub Actions 构建 v1.7.355 APK，然后依次验证：冷启动、热启动、点击上传、选择小米“安全访问”、选取小于 10MB 的图片、发布壁纸，以及头像上传等待反馈。
