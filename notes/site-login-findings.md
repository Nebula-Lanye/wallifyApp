# Wallify 网站登录接入记录

截至当前审阅，`https://lkr2312.dpdns.org/pages/login.php` 提供“邮箱登录”和“用户名登录”两种方式，并包含账户、密码与 CSRF 令牌字段。表单提交目标未以稳定的公开 API 形式暴露，且页面依赖浏览器会话与防伪令牌。

移动应用因此不收集、不转发或存储用户密码，而是通过应用内安全浏览器直接打开原站登录页面。这样可沿用网站现有的 CSRF 与 Cookie 会话保护，并让登录、注册及后续社区操作都保持在网站自身的账户体系中。

公开资料页 `pages/profile.php?id={userId}` 提供用户头像、昵称、个人签名与公开统计；头像路径遵循 `/UserAvatar/{userId}/avatar.jpg`。页面未暴露可由移动应用在不持有网站会话 Cookie 的前提下识别“当前已登录用户”的公开资料 API。原生界面应以用户主动关联的公开个人主页作为头像、昵称和资料来源，账户密码和网站会话仍只由原站浏览器处理。
